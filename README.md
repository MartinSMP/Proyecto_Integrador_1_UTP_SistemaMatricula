## 🧠 Descripción General

El **Sistema de Matrícula** es un software desarrollado íntegramente en **Java** con conexión a **MySQL**, usando el patrón **MVC** cuyo objetivo es gestionar de manera eficiente los procesos de matrícula estudiantil.  
Este proyecto fue desarrollado como parte del curso **Integrador I - Sistemas Software**, aplicando los conocimientos adquiridos en programación orientada a objetos y bases de datos.

---

## ⚙️ Tecnologías Utilizadas

- ☕ **Java SE 8+**  
- 🛢️ **MySQL** (Base de datos relacional)  
- 🧩 **JDBC** para la conexión entre Java y MySQL  
- 🧰 **NetBeans IDE** para el desarrollo del Proyecto 
- 🖥️ **VS Code + GitHub** para control de versiones y documentación  

---

## 🧮 Funcionalidades Principales Implementadas Hasta la Fecha 13/11/2025

- Registro de estudiantes  
- Gestión de cursos
- Gestión de Docentes  
- Asignación de matrículas  
- Consulta y modificación de matriculas/estudiantes  
- Validaciones y reportes básicos
- 🔐 Accesos Autorizados (gestión de usuarios del sistema)
- 📄 Reportes y Constancias (generar PDFs)
